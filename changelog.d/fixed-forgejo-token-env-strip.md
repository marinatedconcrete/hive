- A custom `forgejo.token_env` name is now removed from agent sessions too. A Forgejo token held under a name other than `FORGEJO_TOKEN`, such as `CODE_FORGEJO_PAT`, still reached agents through `env`. The configured name is now registered at boot and on config reload, like the `gitlab.token_env` and `gitea.token_env` names, and stays registered until the process restarts even if a reload stops naming it. Sidecar mode does not receive custom names yet.
